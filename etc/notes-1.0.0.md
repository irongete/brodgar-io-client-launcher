The first launcher. Unzip, run `run.bat`, press Play.

- Keeps the client at the newest release of the channel you pick: **Release**, or **Beta** for the pre-releases.
- Brings its own Java runtime, so nothing has to be installed.
- **Options**: the memory the game is given, how it is cleaned up, window scaling, network addresses, extra Java options, the brodgar.io resource cache proxy, and whether to look for updates at start.
- **Start the client with a console window**, a checkbox: the client runs in a command window that shows what it prints and stays open when it ends in an error — the place to look when something goes wrong.
- Windows only, for now.
